## Worker Architecture

```
Queue / Event Source (Redis / SQS)
         │
         ▼
  Worker Job Consumer Loop
  ┌─────────────────────┐
  │  Concurrency: N     │
  │  ┌─────┬─────┬────┐ │
  │  │Job 1│Job 2│... │ │
  │  └─────┴─────┴────┘ │
  └─────────────────────┘
         │
         ▼
  Prometheus Metrics (:9090/metrics)
  Process telemetry, job counters,
  queue depth, processing latency
```

## Kubernetes HPA Configuration

The generated `k8s/hpa.yaml` auto-scales based on queue depth:

```yaml
apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
metadata:
  name: {component_id}-hpa
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: {component_id}
  minReplicas: 1
  maxReplicas: 10
  metrics:
    - type: External
      external:
        metric:
          name: queue_depth
        target:
          type: AverageValue
          averageValue: "30"
```
